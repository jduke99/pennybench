How to read the statistics

Within each task, take each arm's median across eligible repetitions, then compare Penny / native - 1. A repetition is eligible only when both arms completed. Tasks are the statistical unit; 272 trials are not treated as independent tasks.

The median and 95% bootstrap interval describe task-level changes. P-values use paired Wilcoxon signed-rank on per-task log ratios; the cost Hodges-Lehmann estimate is -27.9%. Table sums add 63 per-task medians; the first-page cost bars sum spending over 116 eligible repetitions.

Agent execution time uses Harbor's agent-execution span, excluding container build and installation. With both eligible repetitions required (53 tasks), median cost fell 30.2% and summed task cost fell 14.2%. Quality tests do not establish equivalence or non-inferiority.
