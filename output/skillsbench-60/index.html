How to read the statistics

Change = Penny / native - 1. Negative means less of the measured resource. The median treats each task equally; the sum is weighted by resource use. Intervals are the report's 95% intervals for the median. Cost is the primary endpoint; other endpoints are secondary and p-values are unadjusted.

p-values use the paired Wilcoxon signed-rank test on per-task log ratios. The cost Hodges-Lehmann estimate is -32.5%. Fresh input totals are small (788 vs. 978 tokens); the +25.0% median should not be confused with total input growth.

Agent execution time comes from Harbor's agent-execution span, not end-to-end benchmark duration. It excludes container build and agent installation, but includes work performed during agent execution. Lines written, an exploratory endpoint, had a 0.0% median change among 46 nonzero comparable pairs.

Methodology, quality & audit.

Harbor execution. SkillsBench verification.

Harbor runs the tasks in isolated containers; SkillsBench supplies the tasks and their verifiers. This report uses the official task rewards, including partial credit where the task awards it, without regrading. PennyBench pairs native and PennyRouter trials with pinned model and harness versions, records model requests, responses and token usage, and audits the retained evidence. Task rewards and execution artifacts make the reported results inspectable.
