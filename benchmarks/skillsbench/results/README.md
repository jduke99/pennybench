# SkillsBench: 60-task results

Published data for the PennyRouter evaluation: `cc-sonnet-native-login` (baseline) versus
`cc-sonnet-proxy-login` (hosted PennyRouter), both Claude Code 2.1.302, Sonnet 5.5, medium
effort, signed-in Claude subscription, per-trial cache isolation.

The [HTML](../../../output/skillsbench-60/index.html),
[PDF](../../../output/pdf/pennybench-skillsbench-60.pdf) and
[Markdown](../../../REPORT.md) reports present the findings. The run's audit is labelled
`partial` because the planned 72-project experiment was stopped after the first 60
scheduled projects. That label describes the stopping point only; the 60 projects ran in
full, passed the audit, and the report documents the stop and the omissions.

## Files in [proxy-full-60/](proxy-full-60/)

| File | Contents |
| --- | --- |
| `REPORT.md`, `stats.json` | Paired statistics for the 57 comparable pairs |
| `metrics.json` | Per-trial cost, tokens, turns, wall clock, reward |
| `trials.json` | Per-trial status, reward, task checksum, agent version |
| `audit.json` | Evidence checks: capture, routing, pins, isolation, pairing |
| `run.json` | Sanitized manifest: experiment hash, dataset pin, arms, exclusions |
| `operational-skip.md` | The one pair stopped by a one-hour backstop and then skipped |

Excluded tasks (15 failed reference-solution checks on the original Apple Silicon machine,
2 missing package inventories, 1 native timeout) are listed in `run.json` and the report.

## What is not published

Raw wire captures (`wire.jsonl`), Harbor logs, agent session files and login metadata stay
in the private run directory. They contain request authorization headers, account and
organization identifiers, local paths and full prompts/responses from third-party task
content. The files above are generated by
[`export_results.py`](../export_results.py), which copies derived data only and redacts
paths, emails and token-shaped strings:

```sh
.venv/bin/python benchmarks/skillsbench/export_results.py runs/proxy-full/<run-id> \
  --out benchmarks/skillsbench/results/proxy-full-60
```

Reviewers who need the raw evidence can request it; it is not a public artifact.
